# Procura AI 

Enterprise  AI  Workforce Platform 

## Stack

- Python 3.11 / FastAPI
- PostgreSQL / Redis
- Docker / Docker Compose
- JWT Authentication
- RBAC Authorization

## Development

```bash
cd backend
uv sync
uv run uvicorn app.main:app --reload
```

## API Docs

- Swagger: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc
